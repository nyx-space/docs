> Reference guides are **technical descriptions** of the machinery and how to operate it. Reference material is **information-oriented**.
-- [_Diataxis_](https://www.diataxis.fr/tutorials/)

This reference includes the API documentation for all of the ANISE libraries. It also contains the mathematical specifications of most calculations used in ANISE.

- **[Almanac](almanac.md)**: Technical details of the central context object and its methods.
- **[Frame](frame.md)**: Definitions of frame types, NAIF IDs, and frame-specific metadata.
- **[Orbit and States](orbit.md)**: Reference for state vectors, orbital elements, and basic propagation.
- **[API Documentation](api/index.md)**: Generated documentation for Rust and Python.
- **[Math Specs](mathspec/orbital_elements.md)**: Detailed mathematical derivations and implementations.
